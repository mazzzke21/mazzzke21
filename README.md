  ### 🚀 Обо мне

  Я увлеченный разработчик игр и программист. Создаю интересные игровые механики, работаю над мультиплеером и пишу скрипты для разных платформ.

### 💻 Чем я занимаюсь:
* 👻 **В разработке:** Работаю над атмосферным хоррором **Echo of the Shift**.
* 🌐 **Фокус сейчас:** Изучение и внедрение мультиплеера в Unity (Netcode for GameObjects, Relay), создание лобби и систем распределения ролей.
* 🛠 **Моддинг:** Пишу аддоны для Garry's Mod на Lua (например, кастомные HUD).
* 🧠 **Интересы:** Изучение искусственного интеллекта и оптимизация промптов для написания чистого кода.
